# CS-370: Current and Emerging Trends in Computer Science

## Project Overview: Deep Q-Learning Pirate Intelligent Agent

This folder contains my Project Two artifact, `TreasureHuntGame_starterCode.html`, which implements a Deep Q-Network (DQN) intelligent agent in Python using TensorFlow and Keras. The agent, a pirate navigating an 8 by 8 grid maze, learns to locate a treasure chest in the bottom-right corner (7, 7) from any valid starting cell while maximizing cumulative reward and avoiding obstacles.

The full reflection, including the design defense, the training loop I built in `qtrain()`, and the ethical responsibilities discussion, is in the main repository README under the CS-370 section. The agent reached full-maze mastery at Epoch 236, with 172 wins in 305.8 seconds.
